# P73/W34.1 — словарь и глаголы

База `922d3fc1968b351418ee503df4294c0be50c508c`. Визуально сверены восемь страниц учебника Ελληνικά Τώρα 1+1 (печатные 66–73, PDF 66–73) и три страницы Τετράδιο Ασκήσεων 1 (печатные 32–34, PDF 30–32). Учитывались подписи карты, текст и упражнения. На стр. 70 только фотография автобуса.

Рассмотрено **96 кандидатов**, включая словарные варианты и готовые сочетания. Принято **79 новых карточек**. У двух существующих карточек добавлены примеры, у одной из прежних парадигм уточнено примечание. Словарь вырос с 508 до 587 карточек, справочник с 34 до 47 парадигм. Примеры составлены для приложения.

## Словарь и T5

Все 508 прежних идентификаторов сохранены, все 79 новых ключей автоматически попадают в T5. При нормализации полного русского перевода новых совпадений нет. Для следующего этапа стоит проверить семантическую близость `κατάστημα / μαγαζί` (магазин), `οδός / δρόμος` (улица), `όμως / αλλά / μα` (но), `μελετάω / διαβάζω` (учиться, работать с текстом), `ωραία / καλά` (хорошо), `έργο / φιλμ` (фильм), `πάρα πολύ / πολύ` (очень, много), `σε / στο / στην` (в, на) и `κύριος / άντρας` (мужчина). У каждой пары вариантов `πάω / πηγαίνω`, `ημέρα / μέρα` и `επάνω / πάνω` одна карточка. Механика T5 и история тренировок сохранены.

## Материал следующего этапа

- Настоящее время на `-άω / -ώ`, употребление `πάω / πηγαίνω`, направления `μπαίνω / βγαίνω` и `ανεβαίνω / κατεβαίνω`.
- Объяснение маршрута с предлогами и наречиями места, лексика еды и транспорта.
- Слабые формы `με / σε`, сочетания `σ’ αγαπάω`, `σ’ ευχαριστώ`, отрицание `ούτε … ούτε`.
- Звательный падеж в обращении по имени и повелительное `έλα`.
- Дни недели, время суток и формы числительных при указании возраста с `χρονών`.
