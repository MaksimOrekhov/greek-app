## Спряжение и нормативные варианты

- `ανεβαίνω`: в тетради W31 упражнение на настоящее время. Справочник дополнительно показывает аорист `ανέβηκα` и два будущих: `θα ανεβαίνω` (процесс или повторение) и `θα ανέβω` (однократный подъём). Вариант простого будущего `θα ανεβώ` указан в примечании. В справочнике представлены шесть лиц для каждой формы.
- `μοβ`, `μπλε` и цветовое `καφέ` не изменяются по роду. Для `μοβ` сохранено современное написание, для `μαντήλι` — вариант из упражнения (также `μαντίλι`), для `καινούργιος` — вариант из урока (также `καινούριος`), для `παντελόνι` — вариант учебника (также `πανταλόνι`). У `Σαββατοκύριακο` словари дают заголовок с прописной, в карточке сохранено строчное написание учебника.
- В карточках цветов и других склоняемых прилагательных используется мужская форма, в примерах показано согласование с конкретными существительными. Формы порядковых числительных помечены числительными. Гостиничные названия типов номеров употреблены как существительные среднего рода.
- Материал следующего этапа: слабые винительные `τον / την / το`, сочетания `στον / στην / στο` для места и направления, согласование прилагательных по роду и падежу.
