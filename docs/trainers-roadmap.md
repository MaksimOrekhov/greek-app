# План развития тренажёров

## Реализовано

1. **T1 — «Соедини пары».** Общая пятираундовая сессия и экран результатов.
2. **T2 — «Найди все правильные варианты».** Отдельная сессия и 49 подготовленных вручную вопросов по четырём темам.
3. **T2.2 — вариативные вопросы.** Каждая десятивопросная тренировка включает шесть сгенерированных и четыре вопроса из проверенного банка. Для каждой из четырёх тем есть три ограниченных шаблона. Они используют проверенные таблицы местоимений, сочетаний с притяжательными формами, согласования είμαι и конечного набора числительных. Генераторы находятся в `src/lib/trainers/generation/`, учебные данные — в `src/data/trainers/generation/verifiedContent.ts`. Проверки сравнивают с независимыми эталонными таблицами на сотнях фиксированных seed.

История недавних генеративных заданий хранится отдельно для темы и шаблона в версионированном localStorage. Сигнатуры включают текст задания и варианты с ключами ответов, но не зависят от порядка показа. История ограничена по размеру; при повреждённом или недоступном хранилище сессия запускается без неё. Она не связана с SRS или Supabase.

Числовые шаблоны используют только конечный список проверенных нейтральных форм в пределах 0–200. Генератор είμαι берёт предложения из ограниченного набора подлежащих и проверенных продолжений; для неправильных вариантов меняет только форму глагола при явно указанном подлежащем. Притяжательные и дательные конструкции строятся из проверенных сочетаний, не заменяя местоимение в неподходящем контексте.

## Возможные следующие механики

Порядок ниже предварительный. Не показывать упражнение как доступное до отдельной реализации и проверки содержимого.

1. **Заполни пропуски** — выбор подходящего слова для контекста.
2. **Расставь по порядку** — сортировка чисел и других знакомых последовательностей.
3. **Собери предложение** — размещение слов в правильном порядке.
4. **Разложи по категориям** — распределение слов по заданным группам.
5. **Найди ошибку** — обнаружение и исправление ошибки готового предложения.
6. **Преобразуй фразу** — изменение лица, числа или грамматической формы.
7. **Memory** — поиск совпадающих пар среди закрытых карточек.

Будущие упражнения могут переиспользовать проверенные учебные таблицы, но новые общие абстракции следует вводить только при конкретной потребности следующей механики.
