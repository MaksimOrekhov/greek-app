# Числительные от 100 до 200

## 1. Сто и числа 101–199

Самостоятельное число 100 — **εκατό** (экато́). Когда к ста добавляется другое число, используется форма **εκατόν**:

| Число | По-гречески | Примерное чтение |
| ---: | --- | --- |
| 100 | **εκατό** | экато́ |
| 101 | **εκατόν ένα** | экато́н э́на |
| 110 | **εκατόν δέκα** | экато́н зэ́ка |
| 120 | **εκατόν είκοσι** | экато́н и́коси |
| 130 | **εκατόν τριάντα** | экато́н триа́нда |
| 140 | **εκατόν σαράντα** | экато́н сара́нда |
| 150 | **εκατόν πενήντα** | экато́н пэни́нда |
| 160 | **εκατόν εξήντα** | экато́н экси́нда |
| 170 | **εκατόν εβδομήντα** | экато́н эвзоми́нда |
| 180 | **εκατόν ογδόντα** | экато́н огзо́нда |
| 190 | **εκατόν ενενήντα** | экато́н энэни́нда |

Для промежуточных чисел добавьте единицы по той же модели: **εκατόν είκοσι πέντε** — 125, **εκατόν σαράντα οκτώ** — 148. Последняя часть числительного согласуется с существительным по знакомым правилам для чисел, оканчивающихся на 1, 3 и 4. Подробнее — в теме [числа от 20 до 100](#/theory/numbers-20-100).

## 2. Число 200

В учебной таблице указана форма **διακόσια** (зиако́сиа). Она подходит к существительным среднего рода: **διακόσια παιδιά** — двести детей. С существительными другого рода форма меняется:

| Род существительного | Форма | Пример |
| --- | --- | --- |
| Мужской | **διακόσιοι** | **διακόσιοι φίλοι** — двести друзей |
| Женский | **διακόσιες** | **διακόσιες γυναίκες** — двести женщин |
| Средний | **διακόσια** | **διακόσια παιδιά** — двести детей |

## 3. Примеры

- **Έχουμε εκατόν δέκα βιβλία.** — У нас 110 книг.
- **Το βιβλίο κοστίζει εκατόν είκοσι ευρώ.** — Книга стоит 120 евро.
- **Διακόσιοι φίλοι είναι εδώ.** — Здесь двести друзей.
- **Διακόσιες γυναίκες είναι εδώ.** — Здесь двести женщин.
